# Monacado — Governing Documents

This directory holds the source references that govern Monacado's design and
implementation. They are inputs to the work, not artifacts generated by it.

## Contents

| File | Role |
| --- | --- |
| `Capsule_Driven_Development_Intro_Cover.docx` | Defines **Capsule-Driven Development (CDD)** — the methodology in which a self-describing JSON-LD capsule is the canonical semantic model. |
| `Monacado_New_Thesis_and_Initial_Site_Map.docx` | The **current product and architecture guide**: thesis, commercial model, authority model, AgentNet integration, CDD operating model, site map, and phased plan. |
| `monacado-color-palette.png` | The **approved visual reference** for Monacado's color palette. |

## Working rule

Where these documents conflict with one another — or where an instruction
conflicts with either — implementation must **surface the material conflict for
an explicit ruling rather than silently resolving it**.
